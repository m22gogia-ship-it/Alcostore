# DRINKS TBILISI — Vercel-ის საჩვენებელი ვერსია

ეს არის **სტატიკური დემო**. არ იღებს რეალურ შეკვეთებს, არ ინახავს მომხმარებლის მონაცემებს და არ ამუშავებს გადახდებს. სიგარეტის გაყიდვა არ არის.

## GitHub / Vercel
1. ამოარქივეთ ZIP.
2. GitHub-ზე შექმენით კერძო (Private) repository და ატვირთეთ ამ საქაღალდის შიგთავსი: `index.html`, `style.css`, `app.js`, `vercel.json`, `README.md`.
3. Vercel → Add New → Project → Import Git Repository → აირჩიეთ ეს repository.
4. Framework Preset: **Other**. Root Directory: **./**. Build Command: დატოვეთ ცარიელი. Output Directory: **./** (თუ მოითხოვს).
5. დააჭირეთ Deploy.
6. Preview მისამართით გაუზიარეთ მეგობარს. ეს პროექტი არაფერს იღებს და არაფერს ინახავს სერვერზე.
