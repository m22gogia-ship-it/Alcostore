# alcostore v1.8 — brand directory

Added visible navigation brand lists from Alcorium by category (source: https://alcorium-store.ge/, checked 2026-11-06). Brands are NOT products. Count beside each brand is the number of products presently in alcostore's own catalog, and is 0 for not-yet-imported brands. Selecting a zero-count brand returns an empty result. No prices or stock are fabricated.

Upload all 7 files to GitHub root; deploy from Vercel.

Limitations: source navigation may truncate some brand listings behind 'სრულად'; this directory covers the inspected navigation entries, not a verified complete inventory. No live supplier synchronization or back-office database is included.
